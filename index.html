About the workshop

Cloud-Network Convergence (CNC) brings cloud computing, edge systems, and communication networks into the same design problem. For applications such as AI inference and IoT sensing, the choice of where to compute depends on bandwidth, latency, and coverage as much as it does on available processing power.

Held in conjunction with the IEEE International Conference on Computer Communications (INFOCOM 2027), the workshop brings together researchers and practitioners to discuss how to allocate these resources, secure access to cloud services, and operate them at scale.

Call for papers

Networks & protocols

  • Computing power networks (CPNs)
  • Data center networks and software-defined WANs
  • Convergence of IoT, wireless, and optical networks
  • Network protocols, including Segment Routing over IPv6 (SRv6)

Cloud & edge systems

  • Scheduling and orchestration of cloud and network resources
  • Operation of cloud and network systems
  • Edge computing for network services
  • Cloud-native approaches to network services

Virtualization, AI & security

  • Network function virtualization for 5G and 6G
  • AI and machine learning for cloud-network convergence
  • Cloud-network architectures for AI and machine learning
  • Security of converged cloud and network systems
